**Alero 0.1.5** — Signed and notarized by Apple / Firmada y aprobada por Apple · 🇦🇷 español abajo

### What's new
- **Signed with an Apple Developer ID and notarized by Apple.** The downloaded app opens normally, without **Open Anyway**.
- **Permissions stay from now on.** Because the signature changes this one time, macOS asks once more for the permissions you use (Accessibility, Screen Recording…). After that, updates keep them.

### Install
If you have 0.1.1 or later, Alero offers this update: **Settings → General → Check Now**. If you have 0.1.0, download `Alero-0.1.5.zip` below and replace it by hand.

macOS 14 or later, Apple Silicon or Intel. Free, open source, **no warranty**: install at your own risk.

**Alero 0.1.5** — Firmada y aprobada por Apple

### Novedades
- **Firmada con Developer ID de Apple y aprobada por Apple (notarizada).** La app que bajás abre normal, sin **Abrir igual**.
- **Los permisos quedan de acá en adelante.** Como la firma cambia esta única vez, macOS te pide una vez más los permisos que usás (Accesibilidad, Grabación de pantalla…). Después, las actualizaciones los mantienen.

### Instalar
Si tenés la 0.1.1 o una más nueva, Alero te ofrece esta actualización: **Ajustes → General → Buscar ahora**. Si tenés la 0.1.0, bajá `Alero-0.1.5.zip` de acá abajo y reemplazala a mano.

macOS 14 o más nuevo, Apple Silicon o Intel. Gratis, de código abierto y **sin garantía**: instalala bajo tu responsabilidad.
