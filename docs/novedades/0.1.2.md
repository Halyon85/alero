**Alero 0.1.2** — fix / arreglo · 🇦🇷 español abajo

### What's fixed
- **Alero no longer quits when arranging windows.** In 0.1.1 it closed every time "What goes here?" or the layout picker on the green button appeared, so Windows (and the green button) stopped working.

### Install
If you have 0.1.1, Alero offers this update: **Settings → General → Check Now**. If you have 0.1.0, download `Alero-0.1.2.zip` below and replace it by hand (the first time: **System Settings → Privacy & Security → Open Anyway**).
If Windows still doesn't move other apps after updating, turn Alero off and on again in **System Settings → Privacy & Security → Accessibility**.

macOS 14 or later, Apple Silicon. Free, open source, **no warranty**: install at your own risk.

**Alero 0.1.2** — arreglo

### Qué se arregló
- **Alero ya no se cierra al acomodar ventanas.** En la 0.1.1 se cerraba cada vez que aparecía "¿Qué va acá?" o el selector de formas del botón verde, así que Ventanas (y el botón verde) dejaban de andar.

### Instalar
Si tenés la 0.1.1, Alero te ofrece esta actualización: **Ajustes → General → Buscar ahora**. Si tenés la 0.1.0, bajá `Alero-0.1.2.zip` de acá abajo y reemplazala a mano (la primera vez: **Ajustes del Sistema → Privacidad y seguridad → Abrir igual**).
Si después de actualizar Ventanas sigue sin mover las otras apps, apagá y volvé a prender Alero en **Ajustes del Sistema → Privacidad y seguridad → Accesibilidad**.

macOS 14 o más nuevo, Apple Silicon. Gratis, de código abierto y **sin garantía**: instalala bajo tu responsabilidad.
