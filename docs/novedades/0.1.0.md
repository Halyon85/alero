**Alero 0.1.0** — first public version / primera versión pública · 🇦🇷 español abajo

Your Mac's notch, put to work: music, calendar, per-app volume, display brightness, a teleprompter that follows your
voice, screenshots, cleanup and an uninstaller for several apps at once — light, private and open source.

### Install
1. Download `Alero-0.1.0.zip` below, unzip it and drag `Alero.app` to Applications.
2. The first time macOS blocks it (it isn't signed with an Apple Developer ID yet): **System Settings → Privacy &
   Security → Open Anyway**. Only once.
3. Alero asks for each permission only when a feature needs it.

macOS 14 or later, Apple Silicon. Free, open source, **no warranty** — install at your own risk.
This version doesn't update itself yet: check this page for new versions (automatic updates are coming).

**Alero 0.1.0** — primera versión pública

El notch de tu Mac, trabajando: música, agenda, volumen por app, brillo de las pantallas, un teleprompter que sigue tu
voz, capturas, limpieza y un desinstalador de varias apps a la vez. Liviana, privada y de código abierto.

### Instalar
1. Bajá `Alero-0.1.0.zip` de acá abajo, descomprimilo y arrastrá `Alero.app` a Aplicaciones.
2. La primera vez macOS la bloquea (todavía no está firmada con un Developer ID de Apple): **Ajustes del Sistema →
   Privacidad y seguridad → Abrir igual**. Una sola vez.
3. Alero pide cada permiso solo cuando una función lo necesita.

macOS 14 o más nuevo, Apple Silicon. Gratis, de código abierto y **sin garantía**: instalala bajo tu responsabilidad.
Esta versión todavía no se actualiza sola: mirá esta página para las nuevas (las actualizaciones automáticas vienen pronto).
