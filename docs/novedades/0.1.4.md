**Alero 0.1.4** — Windows no longer stops working / Ventanas ya no deja de andar · 🇦🇷 español abajo

### What's new
- **Windows and the notch keep working.** After some display changes (for example switching the refresh rate from 60 to 120 Hz), macOS could stop sending mouse movements to Alero without notice: the Windows edges and the green-button layouts disappeared until you restarted the app. Alero now uses its own mouse listener that turns itself back on if macOS switches it off, and checks every 5 seconds that it is still working.

### Install
If you have 0.1.1 or later, Alero offers this update: **Settings → General → Check Now**. If you have 0.1.0, download `Alero-0.1.4.zip` below and replace it by hand (the first time: **System Settings → Privacy & Security → Open Anyway**).

macOS 14 or later, Apple Silicon or Intel. Free, open source, **no warranty**: install at your own risk.

**Alero 0.1.4** — Ventanas ya no deja de andar

### Novedades
- **Ventanas y el notch siguen andando.** Después de algunos cambios de pantalla (por ejemplo, pasar de 60 a 120 Hz), macOS podía dejar de mandarle a Alero los movimientos del mouse sin avisar: desaparecían los bordes de Ventanas y las formas del botón verde hasta reiniciar la app. Ahora Alero usa una escucha del mouse propia que se vuelve a prender si macOS la apaga, y cada 5 segundos revisa que siga andando.

### Instalar
Si tenés la 0.1.1 o una más nueva, Alero te ofrece esta actualización: **Ajustes → General → Buscar ahora**. Si tenés la 0.1.0, bajá `Alero-0.1.4.zip` de acá abajo y reemplazala a mano (la primera vez: **Ajustes del Sistema → Privacidad y seguridad → Abrir igual**).

macOS 14 o más nuevo, Apple Silicon o Intel. Gratis, de código abierto y **sin garantía**: instalala bajo tu responsabilidad.
